# ChemSpace 🧪

> **Archival Notice**: Built originally in **June-July 2024** as a first web project (age 15)

ChemSpace is a website featuring interactive & informative periodic table, element group properties, and periodic table filler game.

## ✨ Key Features

* **Informative Periodic Table**: Click on elements to view physical/chemical properties, applications and discovery.
* **Periodic Table Quiz**: Fill the periodic table with element symbols and track the number of correct answers.
* **Reaction Predictor**: Predict and balance the chemical reaction (legacy).
* **Group Properties**: Reference tool for alkali metals, noble gases, halogens, pnictogens, and other groups.
